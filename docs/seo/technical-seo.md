# Technical SEO and discovery

## Public endpoints
- `/robots.txt` is generated by the Next.js Metadata API and blocks private application areas.
- `/sitemap.xml` lists public static pages, categories, and public catalog products.
- `/llms.txt` describes ANAN for AI assistants and other retrieval clients.
- `/opengraph-image` generates the default 1200×630 social preview image.

## Configuration
Set `NEXT_PUBLIC_SITE_URL` to the canonical HTTPS origin before deploying (for example, `https://anan.com`). The fallback is intended for the current project domain and must be replaced if the production domain differs. Keep `ANAN_API_URL` set to the internal NestJS API origin so sitemap generation can read the public catalog.

## Indexing and privacy
Only public catalog endpoints are used to build product URLs. The sitemap fetch is bounded to 20 pages of 48 products per generation and cached for 30 minutes; category data is cached for one hour. Private account, cart, checkout, seller, admin, authentication and API routes are disallowed in robots.txt.

Robots directives are crawler guidance, not access control. All private data and routes must remain protected by server-side authentication and authorization.

## Operational notes
Submit `/sitemap.xml` in Google Search Console and Bing Webmaster Tools after the production domain is live. Verify the sitemap, canonical URLs, generated Open Graph image, and social previews on the deployed host. Add a branded social image and per-product images when product media becomes available.
